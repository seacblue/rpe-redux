# Fixed-beat model

`rpe_fixed_beat.onnx` is the RPE Redux fixed-tempo beat-evidence model. It is
generated by `scripts/trainFixedBeatModel.py` and is used only to refine the
deterministic TypeScript detector. The shipped artifact contains model weights
only; training material is not part of the repository.

The model predicts frame-level beat evidence. The runtime combines it with a
fixed-grid BPM/phase search and raw attack fitting, so the public result stays
fixed-tempo and keeps sub-frame offset precision.
