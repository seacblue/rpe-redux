### 中文

**新增**

- 批量编辑支持在同一种值形态内多选事件类型，并自动禁用文字、Shader、RGB 与普通数值等不兼容类型的混选；同时新增可复用的设计系统多选控件。

**改进**

- 统一下拉控件使用 `chevronDown` 箭头，保持事件类型选择器与普通字段选择器的视觉一致性。

### English

**Added**

- Support selecting multiple event types from the same value family in batch editing, while disabling incompatible mixes such as text, Shader, RGB, and numeric tracks; also add a reusable design-system multi-select control.

**Improvements**

- Use the `chevronDown` icon consistently across dropdown controls so the event-type selector matches regular field selectors.
