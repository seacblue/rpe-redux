# 工作区空间模型（产品稿）

- 状态：讨论稿，不是实现约定
- 日期：2026-11-10
- 目标：重新定义 Inspector、Workspace 和未来工作室之间的空间关系
- 一句话：让 Inspector 有足够空间，但不让它变成第二个常驻面板；Workspace 始终是主工作区，只在用户同意时临时借给大型任务。

## 1. 背景

Drawer 之所以存在，是因为 Inspector 无法承载一部分任务：列表、素材、波形、生成器、未来工作室等，放进侧栏后会变得过窄，或者需要长期占用大量横向空间。

但 Inspector 不能靠无限变宽来解决这个问题。它一旦常驻变宽，就会变成新的 Drawer，继续挤压 Workspace。

Workspace 也不能被替换成另一个 Inspector。它是编辑器的主工作区，必须始终存在，并且随时可以回到时间轴。

未来的工作室会需要更大的画布、列表或工具组合。这些空间需求是真实的，但不应该继续增加常驻面板，也不应该把整套界面变成可任意停靠的工作台。

本稿只定义空间规则，不决定具体实现。当前 Dockview 方向是否保留，也在待决策项中。

## 2. 用户问题

用户真正需要的不是“所有面板都能自由停靠”，而是：

1. 处理复杂任务时，侧栏保持紧凑，不应该因为内容变宽而永久挤压编辑区。
2. 当侧栏放不下时，可以把大型内容放到主工作区。
3. 主工作区始终能回到时间轴，并且回到原来的编辑位置。
4. 能预期空间怎么变化，而不是每次打开页面都被自动挤窄。

## 3. 目标与非目标

### 目标

- Inspector 的宽度只在紧凑范围内调整，不展开成 Drawer，也不覆盖 Workspace。
- 大型内容可以被用户显式提升到 Workspace。
- Workspace 始终保留，切换模式不销毁时间轴状态。
- 工作室作为 Workspace 的一种模式存在，而不是新的常驻 Dock。
- 空间变化可逆、可预测、可持久化。

### 非目标

- 任意停靠、浮动窗口、自由拖拽排列。
- Inspector 覆盖 Workspace，或滑出成宽 Drawer。
- 让 Workspace 永久变成 Inspector。
- 让 Inspector 自动无限变宽。
- 每个页面都拥有自己的独立窗口。
- 多显示器窗口编排。
- 把侧边栏、工具栏、状态栏做成七个可互换的 Dock。

## 4. 空间角色

### Workspace：永久锚点

Workspace 是唯一的主工作区，同一时刻只显示一个模式：

- `timeline`：时间轴，默认模式。
- `preview`：预览。
- `studio:<id>`：某个工作室。

Workspace 不会被删除。打开大型内容时，它切换模式；关闭时回到时间轴。时间轴的播放头、当前判定线、多线选择和时间原点保留。

### Inspector：可伸缩侧栏

Inspector 是常驻侧栏，负责：

- 当前对象的属性。
- 轻量页面和工具。
- 需要与 Workspace 同时查看的内容。

Inspector 有明确的最小、默认和紧凑最大宽度。用户可以拖宽，但只在侧栏范围内调整，不覆盖 Workspace，也不滑出成大面板。内容放不下时，优先在 Inspector 内上下分层；仍然放不下，才去 Workspace。

### Studio：Workspace 的一种模式

工作室不是新的 Dock，也不是新的常驻面板。它是一类 Workspace 模式，拥有：

- 自己的主画布或主列表。
- 可选的 Inspector 页面作为侧边控制。
- 明确的进入和退出动作。

关闭工作室后，Workspace 回到时间轴，而不是留下一个新的常驻区域。

### Sidebar：导航，不占空间

Sidebar 只负责导航和入口，不承担内容展示。它不应该因为打开某个页面而变宽。

## 5. 核心规则

1. **Workspace 永远存在。** 任何时候都必须有一个明确的方式回到时间轴。

2. **Inspector 不展开成 Drawer。** 宽度只在紧凑范围内调整，不覆盖 Workspace，也不滑出成宽面板。

3. **大型内容由用户决定去向。** 页面可以提供“在检查器中打开”和“在工作区打开”两个入口；默认值可以不同，但用户的选择必须可见、可撤销。

4. **提升到 Workspace 是临时的。** 关闭大型内容后回到时间轴，不改变时间轴状态。

5. **同一时刻只有一个 Workspace 模式。** 工作室之间不并排、不堆叠、不形成新的常驻面板。

6. **空间状态可持久化，但只持久化用户明确调整过的部分。** Inspector 宽度可以保存；临时打开的工作室默认不作为启动状态恢复。

7. **不做隐式扩张。** 打开一个页面不会自动把 Inspector 撑到最大，也不会自动把 Workspace 挤到最小。

## 6. 交互设计

### 6.1 Inspector 宽度

- 拖动 Inspector 左/右边缘调整宽度。
- 双击边缘恢复默认宽度。
- 页面标题栏提供“在工作区展开”；它不加宽 Inspector，只把页面提升到 Workspace。
- 不存在宽 Drawer 状态，也没有覆盖式侧栏。
- 宽度只在紧凑范围内调整；最大宽度以可读性为准，建议不超过 `min(420px, 38% 窗口宽度)`。
- 窗口变窄时，实际宽度按上限收缩，但不小于 Inspector 最小宽度。
- 内容放不下时，先改成上下分层、分节或折叠；仍然放不下，使用“在工作区打开”。

建议的宽度值：

| 值          | 含义                   | 是否持久化 |
| ----------- | ---------------------- | ---------- |
| `min`       | 最小可读宽度           | 否         |
| `preferred` | 用户拖动后的默认宽度   | 是         |
| `max`       | 当前窗口允许的紧凑上限 | 否         |

### 6.2 把大型内容放进 Workspace

每个适合提升的页面提供一个明确入口：

- “在工作区打开”
- 或放进页面标题栏的更多菜单

打开后：

- Workspace 切换到对应模式。
- 顶部显示模式名称和“返回时间轴”。
- Inspector 在进入模式时平滑收起，把宽度让给 Workspace；返回时恢复展开前的页面和宽度。
- 页面自己的返回动作和时间轴的返回动作必须一致。

如果页面已经在 Inspector 中打开，用户再次选择“在工作区打开”时，应该移动而不是复制页面状态。

### 6.3 工作室

工作室是一种可注册的 Workspace 模式，例如：

- 素材工作室
- 波形工作室
- 时间轴多线工作室
- 未来的渲染/导出工作台

工作室可以：

- 占用整个 Workspace。
- 需要辅助检查器时由页面自己提供属性列；进入模式后宿主 Inspector 默认收起。
- 拥有自己的工具栏行或局部命令。

工作室不可以：

- 常驻在侧栏。
- 在打开时自动改变整个 Shell 的 Dock 结构。
- 与另一个工作室并排成为新的常驻区域。

### 6.4 返回时间轴

返回动作必须恢复：

- 播放头位置。
- 当前判定线。
- 多线选择和多线滚动位置。
- 时间轴缩放和原点。
- 如果工作室有未保存内容，先询问是否放弃。

返回后不保留工作室的临时面板状态，除非工作室自己声明需要恢复。

## 7. 状态与持久化

建议只持久化以下内容：

- Inspector 的 `preferredWidth`。
- Inspector 最后一次打开的页面（可选）。
- 每个页面最后一次选择的打开位置（可选，后续再做）。

不持久化：

- 临时打开的工作室。
- 拖动中的宽度。
- 页面内部的临时滚动或选择，除非该页面自己负责。

## 8. 边界情况

- **窗口很窄**：Inspector 只能到最小宽度，Workspace 保持最小可用宽度；大型内容提示用户使用 Workspace 模式。
- **Inspector 内容太长**：在 Inspector 内上下分层、折叠或滚动，不增加宽度。
- **页面需要比 Workspace 更大的空间**：先不引入全屏模式，作为后续工作室能力单独设计。
- **同时打开多个大型内容**：只保留一个 Workspace 模式；切换时提示或直接替换，不形成堆叠。
- **打开工作室时**：Inspector 平滑收起，Workspace 扩展；返回时恢复之前的页面和宽度。
- **用户从不调整宽度**：使用默认宽度，不因为页面内容自动变化。

## 9. 验收标准

- 用户可以拖动 Inspector 宽度，并在重启后保留。
- 打开普通页面不会改变 Inspector 宽度，也不会出现覆盖/滑出状态。
- 大型页面提供“在工作区打开”，打开后时间轴让位、Inspector 收起，但可以一键返回。
- 返回时间轴后，Inspector 恢复展开前的页面，播放头和当前判定线保持不变。
- Inspector 达到紧凑上限时，Workspace 仍保持最小宽度。
- 不依赖任意停靠、浮动窗口或自定义 Dock 布局也能完成以上流程。

## 10. 分阶段建议

### 阶段 0：冻结 Dock 扩张

- 暂停新增停靠、浮动、排列和横竖变体。
- 评估现有 Dockview 是否只保留“可调整尺寸 + 宽度持久化”，其余能力下线。

### 阶段 1：Inspector 空间边界

- 明确最小、默认和紧凑最大宽度。
- 删除 Drawer 的宽度揭示和覆盖展开。
- 保存用户宽度偏好。
- 把放不下的页面改为上下分层、分节或折叠。

### 阶段 2：单个页面的 Workspace 提升

- 选择一个最适合的真实页面作为试点。
- 实现“在工作区打开”和“返回时间轴”。
- 验证状态恢复和窄窗口行为。

### 阶段 3：工作室注册

- 把工作室定义为 Workspace 模式。
- 复用同一套进入/退出和状态恢复规则。
- 再决定是否需要每个页面记住打开位置。

## 11. 待决策

1. 时值工作室是否继续加入波形对齐、Tap Tempo 和批量 BPM 缩放？
2. 判定线工作室是否加入选中线的缩略预览？
3. 素材工作室是否加入素材网格和引用关系视图？
4. 打开工作室后，Inspector 是否提供“固定为属性栏”的用户偏好？当前进入模式时收起，返回时恢复。
5. 工作室未保存时，返回时间轴是否必须确认？
6. 重启后是否恢复上次的工作室，还是始终回到时间轴？
7. 现有 Dockview 是保留为固定分栏的底层，还是整体替换为更简单的分栏组件？

## 12. 当前建议

先按“空间协商”模型推进，不按“自由布局”模型推进。

最小可行版本只需要：

- Inspector 紧凑宽度，不展开成 Drawer。
- 一个页面提升到 Workspace。
- 返回时间轴并恢复状态。

如果这三件事能解决用户问题，就不需要继续维护任意停靠和浮动窗口。Dockview 可以降级为固定分栏的实现细节，甚至完全移除。

## 13. 三个 Drawer 的具体去向

BPM、判定线、素材目前都是“左侧列表 + 右侧属性”的 Drawer。它们之所以需要变宽，是因为列表和属性被并排放在 Inspector 里。

按新规则，三者不再共用一种形态，而是按“是否需要同时看时间轴”和“是否需要大面积主内容”分开。

| 内容 | 需要同时看时间轴 | 新位置 | 形态 |
| --- | --- | --- | --- |
| BPM / 时值 | 是 | Inspector + Workspace | 默认上下分层，显式展开为时值工作室 |
| 判定线 | 管理时不需要，编辑当前线时需要 | Workspace + Inspector | 管理工作室 + 当前线快捷属性 |
| 素材 | 否 | Workspace | 文件夹树 + 素材网格 + 大预览 |

### 13.1 BPM / 时值

**默认留在 Inspector，需要更大空间时显式展开为时值工作室。**

原因：选择时值点会移动播放头，编辑 BPM 和偏移时通常需要同时看时间轴。默认把 BPM 放进 Workspace 会让时间轴消失，反而不适合这个任务；但它仍然值得拥有一个专门的展开形态，用于查看完整列表和整段时值分布。

Inspector 内的结构改为上下分层：

1. 顶部：谱面偏移、自动检测入口。
2. 中部：时值点列表，固定高度并单独滚动；每行只显示拍点和 BPM。
3. 下部：当前时值点的 BPM、起始拍等属性。
4. 底部：新增、删除。

关键约束：

- 列表和属性不再左右并排，Inspector 不因打开 BPM 而变宽。
- 列表高度受限，属性区始终可见。
- 选中列表行仍然移动播放头并跟随播放。
- 展开为时值工作室后，左侧显示完整时值表和“间隔”列，右侧保留属性、节拍器和自动检测入口，底部增加可点击的 BPM 色带图。

### 13.2 判定线

**管理进 Workspace，当前线属性留在 Inspector。**

判定线需要树形层级、文件夹分组、拖拽排序、多选和批量操作，这些不适合塞进紧凑侧栏。因此拆成两个入口：

- **判定线管理**：Workspace 模式。
  - 左侧是判定线树和文件夹。
  - 右侧是选中线或批量选择的属性与操作。
  - 可以包含一个选中线的缩略预览区域。
  - 顶部有“返回时间轴”。
- **当前线属性**：Inspector 页面。
  - 只显示当前活动线的常用属性。
  - 适合一边看时间轴一边微调。

这样，简单地改当前线属性不需要离开时间轴；需要整理线结构时才进入 Workspace。

### 13.3 素材

**整体进入 Workspace，成为素材工作室。**

素材需要文件夹树、网格、缩略图和大预览，是最不适合 Inspector 的一类内容。

素材工作室的布局：

- 左侧：文件夹树。
- 中部：素材网格。
- 右侧：选中素材的大预览、元数据和操作。
- 顶部：导入、新建文件夹、删除、返回时间轴。
- Inspector 可以保留选中素材的简要信息，但不作为主要浏览入口。

打开素材时，时间轴让位；关闭后回到时间轴，播放头和判定线状态不变。

### 13.4 共同规则

- 三者都不再通过加宽 Inspector 来展示。
- Inspector 不出现左右两列；需要更多内容时改为上下分层或分节。
- 放不进 Inspector 的内容，才提升为 Workspace 模式。
- Workspace 模式必须有清晰的返回时间轴入口。
- 工作室只借用 Workspace，不新增常驻面板，也不改变 Shell 的布局结构。

## 14. 动效与转场

Workspace 从时间轴切换到工作室，不能让用户感觉“播放界面突然消失了”。它应该像同一个工作区换了内容，而不是跳到了另一个页面。

### 14.1 原则

- **外壳框架不动。** 标题栏、工具栏、侧边栏和状态栏保持原位；Inspector 列宽平滑收起，Workspace 在同一个窗口行内扩展。
- **只换 Workspace 内容。** 时间轴和工作室在同一个矩形里交叉过渡，不出现页面跳转。
- **不是 Drawer。** 不使用从侧边滑出的横向转场，否则会重新变成 Drawer 的观感。
- **方向清楚。** 进入工作室和返回时间轴使用同一套空间逻辑，返回时反向播放。
- **短。** 总时长控制在 180–240ms，避免用户等待动画。
- **可打断。** 转场期间接受 Esc；转场结束后焦点落在模式标题或返回按钮上。

### 14.2 推荐的转场

进入工作室：

1. Workspace 顶部模式条先更新，显示“时间轴 → 素材工作室”或“← 返回时间轴”。
2. Inspector 列宽在 200–240ms 内平滑收起到 0，Workspace 同步扩展，不出现横向滑入。
3. 时间轴内容在 120–160ms 内轻微后退：透明度降到 0，缩放从 1 到 0.985。
4. 工作室内容在 160–220ms 内进入：透明度从 0 到 1，向上移动 8px 后归位，缩放从 0.99 到 1。
5. 两段动画短暂重叠，避免中间出现空白帧。
6. 转场结束后，焦点进入工作室标题或第一个可操作控件。

返回时间轴：

- 使用同一套动画反向播放；Inspector 展开到进入前的宽度，并恢复之前的页面。
- 不播放横向滑动，也不让时间轴从屏幕外飞入。
- 返回后恢复播放头、当前判定线和多线选择。
- 如果进入时暂停了播放，返回时恢复进入前的播放状态。

### 14.3 从 Inspector 提升到 Workspace

“在工作区打开”是一个空间迁移动作，应该让用户感觉内容从 Inspector 进入了 Workspace：

- 优先使用共享元素：页面标题、缩略图或主内容卡片从 Inspector 中的位置扩展到 Workspace。
- 如果共享元素成本太高，退化为“Inspector 内容淡出并收拢 + Workspace 内容淡入并轻微上移”。
- 不使用从 Inspector 边缘横向滑出的动画，否则会像 Drawer 再次出现。

### 14.4 从侧边栏打开工作室

- 侧边栏项目保持选中状态。
- Workspace 内容用淡入 + 轻微上移动画出现。
- 不从侧边栏方向横向滑入；那会把“切换主工作区”误读成“抽屉打开”。

### 14.5 减少动态效果

- `prefers-reduced-motion` 下取消位移和缩放，只保留极短的淡入淡出，或直接切换。
- 动画期间不阻塞 transport 和 Esc。
- 不使用整页路由转场或缩放整个应用窗口。

### 14.6 反模式

- 播放界面突然硬切到工作室。
- 工作室从屏幕边缘横向滑入。
- 转场时 Workspace 尺寸变化，导致画布重排。
- 转场超过 300ms，或需要等动画结束才能操作。
- 进入工作室后没有任何“当前模式 / 返回时间轴”提示。
- 转场后播放状态、播放头或当前判定线丢失。

### 14.7 待决策

- 进入工作室时是否默认暂停播放？建议默认暂停并记住状态，返回时恢复。
- 共享元素转场是否作为第一版要求，还是先做交叉淡入？
- 第一次进入工作室是否显示一次性提示：“按 Esc 返回时间轴”。

## 15. 三个 Inspector 页的落地形态

当前实现按“紧凑 Inspector + Workspace 模式”落地。三个页面共用同一个规则：

- 侧边栏按钮打开紧凑 Inspector 页。
- 紧凑页把列表/树放在上方，把当前对象的属性放在下方；中间是可拖动的分栏缝，双击复位，方向键微调。
- 标题栏的“在工作区展开”把同一页面提升为 Workspace 模式。
- 进入 Workspace 后，Inspector 平滑收起，Workspace 扩展到整行；返回时恢复展开前的页面、宽度和播放状态。
- 临时打开的 Workspace 模式不写进会话恢复。
- Workspace 模式切换只交叉淡入时间轴与页面内容，并同步过渡 Inspector 列宽。
- 模式期间点击侧边栏任一页面，先回到时间轴，再打开目标 Inspector 页，避免在隐藏的 Inspector 里切换内容。

### 15.1 时值

紧凑 Inspector：

- 上方是时间偏移、时值点列表和新增/删除。
- 下方是当前时值点的时间、BPM、节拍器，以及自动检测 BPM 与偏移值的入口。
- 选中列表行仍会移动播放头，便于一边听一边改。
- 没有时值点时，列表和新增占满页面，自动检测入口固定在底部，不显示空的属性分栏。

Workspace 模式：

- 左侧是完整时值表，增加“间隔”列，显示相邻时值点之间的拍数差。
- 右侧是当前时值点的属性、节拍器和自动检测入口。
- 底部新增时值图：每个时值点是一段可点击的 BPM 色带，点击后选中该点并移动播放头。
- 顶部汇总时值点数量、谱面偏移和最后一个时值点的位置。

### 15.2 判定线

紧凑 Inspector：

- 上方是判定线树和分组，底部固定新增判定线、新增分组和删除。
- 下方是当前线或多选线的属性，包括类型、绑定 UI、Z 顺序、遮罩、贴图、BPM 倍率和组合方式。
- 树的选择与属性表单共享同一份选择状态；不需要来回切换“列表/属性”视图。
- 没有判定线且没有选中文件夹时，树占满页面，不显示空的属性分栏。

Workspace 模式：

- 左侧是完整高度的判定线树，适合整理分组和在多选范围内批量修改。
- 右侧是属性表单，批量编辑和多选状态直接可见。
- 顶部汇总判定线数量、分组数量和当前选择数量。
- 属性表单下方是控制曲线编辑器，支持 X 位置、Y 位置、倾斜、大小和透明度五条轨道。
- 所有新增、删除、重命名、拖拽排序和批量操作仍在同一页面完成。

### 15.3 素材

紧凑 Inspector：

- 上方是文件夹树、导入素材、新建文件夹、删除分组。
- 下方是选中素材的预览、重命名和外部打开；图片、音频和 shader 使用各自的预览。
- 没有选中素材时，下方不显示详情区，文件夹树占满页面。

Workspace 模式：

- 左侧是素材树和导入/分组操作。
- 右侧是大预览、元数据和操作，图片按原始比例显示；没有选中素材时右侧不占位。
- 顶部汇总素材数量和文件夹数量。
- 导入、删除、重命名、文件夹整理和 shader 参数配置与紧凑页使用同一套行为。

### 15.4 判定线控制曲线

判定线的 X/Y 不是普通静态属性，而是 RPE 的 note control 曲线：横轴是音符下落距离，纵轴是该轨道在对应距离上的倍率或角度。

- X 位置使用 `posControl`，影响音符横向位置倍率。
- Y 位置使用 `yControl`，影响音符纵向位置倍率。
- 倾斜使用 `skewControl`，影响音符的横向剪切角。
- 大小和透明度分别使用 `sizeControl`、`alphaControl`。
- 曲线评估与运行时一致：控制点按距离排序，段内使用控制点自带的 `easing` 插值。
- 编辑方式：点击曲线区域添加点，拖动点改变距离或数值；选中点后可以在下方精确输入距离和数值。
- 手势期间只更新本地草稿，松开指针才提交一次，避免一次拖动产生几十条撤销记录。
- “重置曲线”删除该线的自定义轨道，回到中性默认；“删除点”删除当前选中的控制点。
- 紧凑 Inspector 显示同样的编辑器；Workspace 模式提供更高的曲线画布。

### 15.5 动效落地

- 进入模式时，Inspector 宽度在 200–240ms 内收起到 0，Workspace 同步扩展。
- 时间轴在 160ms 内后退并淡出，模式内容在 180–220ms 内淡入并上移 8px。
- 返回时反向播放，不出现横向滑入。
- 进入模式时暂停播放，并记录进入前的播放状态；返回时恢复。
- `prefers-reduced-motion` 下去掉位移和缩放，只保留极短淡入。
- Escape 与“返回时间轴”走同一个退出动作；如果 Workspace 打开期间用户切换了 Inspector 页面，返回时不会强行覆盖当前页面。
