# 工作区空间模型（产品稿）

- 状态：讨论稿，不是实现约定
- 日期：2026-11-10
- 目标：重新定义 Inspector、Workspace 和未来工作室之间的空间关系
- 一句话：让 Inspector 有足够空间，但不让它变成第二个常驻面板；Workspace 始终是主工作区，只在用户同意时临时借给大型任务。

## 1. 背景

Drawer 之所以存在，是因为 Inspector 无法承载一部分任务：列表、素材、波形、生成器、未来工作室等，放进侧栏后会变得过窄，或者需要长期占用大量横向空间。

但 Inspector 不能靠无限变宽来解决这个问题。它一旦常驻变宽，就会变成新的 Drawer，继续挤压 Workspace。

Workspace 也不能被替换成另一个 Inspector。它是编辑器的主工作区，必须始终存在，并且随时可以回到时间轴。

未来的工作室会需要更大的画布、列表或工具组合。这些空间需求是真实的，但不应该继续增加常驻面板，也不应该把整套界面变成可任意停靠的工作台。

本稿只定义空间规则，不决定具体实现。当前 Dockview 方向是否保留，也在待决策项中。

## 2. 用户问题

用户真正需要的不是“所有面板都能自由停靠”，而是：

1. 处理复杂任务时，侧栏保持紧凑，不应该因为内容变宽而永久挤压编辑区。
2. 当侧栏放不下时，可以把大型内容放到主工作区。
3. 主工作区始终能回到时间轴，并且回到原来的编辑位置。
4. 能预期空间怎么变化，而不是每次打开页面都被自动挤窄。

## 3. 目标与非目标

### 目标

- Inspector 默认保持紧凑；用户显式展开时，Inspector 本体向左覆盖 Workspace。
- 大型内容可以被用户显式展开为宽 Inspector。
- Workspace 始终保留，展开/收起不销毁时间轴状态。
- 工作室作为 Inspector 的展开态存在，而不是新的常驻 Dock。
- 空间变化可逆、可预测、可持久化。

### 非目标

- 任意停靠、浮动窗口、自由拖拽排列。
- 展开态自动改变整个 Shell 的 Dock 结构。
- 让 Workspace 永久变成 Inspector。
- 让 Inspector 自动无限变宽。
- 每个页面都拥有自己的独立窗口。
- 多显示器窗口编排。
- 把侧边栏、工具栏、状态栏做成七个可互换的 Dock。

## 4. 空间角色

### Workspace：永久锚点

Workspace 是唯一的主工作区，同一时刻只显示一个模式：

- `timeline`：时间轴，默认模式。
- `preview`：预览。
- `studio:<id>`：某个工作室。

Workspace 不会被删除。打开大型内容时，它切换模式；关闭时回到时间轴。时间轴的播放头、当前判定线、多线选择和时间原点保留。

### Inspector：可伸缩侧栏

Inspector 是常驻侧栏，负责：

- 当前对象的属性。
- 轻量页面和工具。
- 需要与 Workspace 同时查看的内容。

Inspector 默认保持紧凑，有明确的最小、默认和紧凑最大宽度。用户可以拖宽，但只在侧栏范围内调整。内容放不下时，优先在 Inspector 内上下分层；仍然放不下，使用“展开”：Inspector 本体向左变宽，直到覆盖 Workspace，而不是把页面搬到另一个区域。

### Studio：Inspector 的展开态

工作室不是新的 Dock，也不是新的常驻面板。它是 Inspector 的一种展开态，拥有：

- 自己的主列表、表格或画布。
- 与紧凑页相同的标题行、帮助入口和右侧动作位。
- 明确的展开和返回动作。

展开时 Inspector 覆盖 Workspace；Workspace 不换页、不缩放，也不重新布局。关闭工作室后 Inspector 收回原宽度，Workspace 原样露出。

### Sidebar：导航，不占空间

Sidebar 只负责导航和入口，不承担内容展示。它不应该因为打开某个页面而变宽。

## 5. 核心规则

1. **Workspace 永远存在。** 展开的 Inspector 覆盖它，但时间轴、播放头和当前选择不被替换；返回后原样露出。

2. **Inspector 默认紧凑，只有显式展开才覆盖 Workspace。** 展开和返回都在同一标题行完成，按钮位置不变。

3. **大型内容由用户决定是否展开。** 页面只提供一个可见的展开入口；默认保持紧凑，用户的选择必须可撤销。

4. **展开是临时的。** 收起后回到原 Inspector 页面和宽度，不改变 Workspace 状态。

5. **同一时刻只有一个展开的 Inspector 页。** 工作室之间不并排、不堆叠、不形成新的常驻面板。

6. **空间状态可持久化，但只持久化用户明确调整过的部分。** Inspector 宽度可以保存；临时展开的工作室默认不作为启动状态恢复。

7. **不做隐式扩张。** 打开一个页面不会自动把 Inspector 撑到最大；只有用户点击展开才会覆盖 Workspace。

## 6. 交互设计

### 6.1 Inspector 宽度

- 拖动 Inspector 左/右边缘调整宽度。
- 双击边缘恢复默认宽度。
- 页面标题栏提供“展开”；它把 Inspector 本体向左变宽，直到覆盖 Workspace，而不是把页面搬到 Workspace。
- 展开态的标题行和紧凑态使用同一组按钮：帮助问号跟在名称后，展开/返回在右侧同一位置。
- 不存在独立的宽 Drawer；展开态仍是 Inspector，只是宽度覆盖 Workspace。
- 宽度只在紧凑范围内调整；最大宽度以可读性为准，建议不超过 `min(420px, 38% 窗口宽度)`。
- 窗口变窄时，实际宽度按上限收缩，但不小于 Inspector 最小宽度；展开态覆盖到侧边栏为止。
- 内容放不下时，先改成上下分层、分节或折叠；仍然放不下，使用“展开”。

建议的宽度值：

| 值          | 含义                    | 是否持久化 |
| ----------- | ----------------------- | ---------- |
| `min`       | 最小可读宽度            | 否         |
| `preferred` | 用户拖动后的默认宽度    | 是         |
| `max`       | 当前窗口允许的紧凑上限  | 否         |
| `expanded`  | 覆盖 Workspace 后的宽度 | 否         |

### 6.2 把大型内容提升为展开的 Inspector

每个适合提升的页面提供一个明确入口：

- “展开”
- 或放进页面标题栏的更多菜单

打开后：

- Inspector 从当前宽度向左展开，直到覆盖 Workspace；Workspace 不换页、不缩放、不重新布局。
- 标题行保持原位：名称、帮助问号、返回和关闭按钮都在原来的槽位。
- 返回按钮是展开按钮的同一位置和同一图形，只是方向相反。
- 页面内容在 Inspector 内切换为宽布局；宽布局按最终宽度稳定铺在右侧，展开过程只揭开面板，不再让内容随宽度重新排版。
- 过渡期间紧凑页保持挂载并退到下层、停止接收输入；宽布局显示期间它继续作为不可交互的下层存在，返回时先恢复紧凑页，再收起宽布局。
- 返回时 Inspector 收回展开前的宽度和页面，Workspace 原样露出。

如果页面已经在 Inspector 中打开，用户再次选择“展开”时，应该复用同一页面状态，而不是复制一份。

### 6.3 工作室的展开态

工作室是一种可注册的 Inspector 展开页，例如：

- 素材工作室
- 波形工作室
- 时间轴多线工作室
- 未来的渲染/导出工作台

工作室可以：

- 覆盖整个 Workspace。
- 使用 Inspector 标题行作为自己的标题、帮助和返回入口。
- 拥有自己的工具栏行或局部命令。

工作室不可以：

- 常驻在侧栏之外。
- 打开时改变整个 Shell 的 Dock 结构。
- 与另一个工作室并排成为新的常驻区域。

### 6.4 返回时间轴

返回动作必须恢复：

- 播放头位置。
- 当前判定线。
- 多线选择和多线滚动位置。
- 时间轴缩放和原点。
- 如果工作室有未保存内容，先询问是否放弃。

返回后不保留工作室的临时面板状态，除非工作室自己声明需要恢复。

## 7. 状态与持久化

建议只持久化以下内容：

- Inspector 的 `preferredWidth`。
- Inspector 最后一次打开的页面（可选）。
- 每个页面最后一次选择的打开位置（可选，后续再做）。

不持久化：

- 临时打开的工作室。
- 拖动中的宽度。
- 页面内部的临时滚动或选择，除非该页面自己负责。

## 8. 边界情况

- **窗口很窄**：Inspector 只能到最小宽度；展开态覆盖到侧边栏为止，页面内部滚动。
- **Inspector 内容太长**：在 Inspector 内上下分层、折叠或滚动，不增加宽度。
- **页面需要比 Workspace 更大的空间**：展开 Inspector 覆盖 Workspace；不引入全屏模式。
- **同时打开多个大型内容**：只保留一个展开页；切换时替换，不形成堆叠。
- **打开工作室时**：Inspector 向左展开，Workspace 保持原位；返回时 Inspector 收回，Workspace 原样露出。
- **用户从不调整宽度**：使用默认宽度，不因为页面内容自动变化。

## 9. 验收标准

- 用户可以拖动 Inspector 宽度，并在重启后保留。
- 打开普通页面不会改变 Inspector 宽度，也不会出现覆盖状态。
- 大型页面提供“展开”，打开后 Inspector 向左覆盖 Workspace，但可以一键返回。
- 返回后 Inspector 恢复展开前的页面和宽度，播放头、当前判定线和 Workspace 状态保持不变。
- 展开和返回使用同一标题行、同一按钮槽位；问号紧跟名称。
- Inspector 达到紧凑上限时，Workspace 仍保持最小宽度；只有展开态才覆盖它。
- 不依赖任意停靠、浮动窗口或自定义 Dock 布局也能完成以上流程。

## 10. 分阶段建议

### 阶段 0：冻结 Dock 扩张

- 暂停新增停靠、浮动、排列和横竖变体。
- 评估现有 Dockview 是否只保留“可调整尺寸 + 宽度持久化”，其余能力下线。

### 阶段 1：Inspector 空间边界

- 明确最小、默认和紧凑最大宽度。
- 删除 Drawer 的宽度揭示和覆盖展开。
- 保存用户宽度偏好。
- 把放不下的页面改为上下分层、分节或折叠。

### 阶段 2：单个页面的 Inspector 展开

- 选择一个最适合的真实页面作为试点。
- 实现“展开”和“返回时间轴”。
- 验证状态恢复和窄窗口行为。

### 阶段 3：工作室注册

- 把工作室定义为 Inspector 展开态。
- 复用同一套进入/退出和状态恢复规则。
- 再决定是否需要每个页面记住展开位置。

## 11. 待决策

1. 时值工作室是否继续加入波形对齐、Tap Tempo 和批量 BPM 缩放？
2. 判定线工作室是否加入选中线的缩略预览？
3. 素材工作室是否加入素材网格和引用关系视图？
4. 打开工作室后，Inspector 是否提供“固定为属性栏”的用户偏好？当前进入模式时收起，返回时恢复。
5. 工作室未保存时，返回时间轴是否必须确认？
6. 重启后是否恢复上次的工作室，还是始终回到时间轴？
7. 现有 Dockview 是保留为固定分栏的底层，还是整体替换为更简单的分栏组件？

## 12. 当前建议

先按“空间协商”模型推进，不按“自由布局”模型推进。

最小可行版本只需要：

- Inspector 紧凑宽度，不展开成 Drawer。
- 一个页面提升到 Workspace。
- 返回时间轴并恢复状态。

如果这三件事能解决用户问题，就不需要继续维护任意停靠和浮动窗口。Dockview 可以降级为固定分栏的实现细节，甚至完全移除。

## 13. 三个 Drawer 的具体去向

BPM、判定线、素材目前都是“左侧列表 + 右侧属性”的 Drawer。它们之所以需要变宽，是因为列表和属性被并排放在 Inspector 里。

按新规则，三者不再共用一种形态，而是按“是否需要同时看时间轴”和“是否需要大面积主内容”分开。

| 内容 | 需要同时看时间轴 | 新位置 | 形态 |
| --- | --- | --- | --- |
| BPM / 时值 | 是 | Inspector + Workspace | 默认上下分层，显式展开为时值工作室 |
| 判定线 | 管理时不需要，编辑当前线时需要 | Workspace + Inspector | 管理工作室 + 当前线快捷属性 |
| 素材 | 否 | Workspace | 文件夹树 + 素材网格 + 大预览 |

### 13.1 BPM / 时值

**默认留在 Inspector，需要更大空间时显式展开为时值工作室。**

原因：选择时值点会移动播放头，编辑 BPM 和偏移时通常需要同时看时间轴。默认把 BPM 放进 Workspace 会让时间轴消失，反而不适合这个任务；但它仍然值得拥有一个专门的展开形态，用于查看完整列表和整段时值分布。

Inspector 内的结构改为上下分层：

1. 顶部：谱面偏移、自动检测入口。
2. 中部：时值点列表，固定高度并单独滚动；每行只显示拍点和 BPM。
3. 下部：当前时值点的 BPM、起始拍等属性。
4. 底部：新增、删除。

关键约束：

- 列表和属性不再左右并排，Inspector 不因打开 BPM 而变宽。
- 列表高度受限，属性区始终可见。
- 选中列表行仍然移动播放头并跟随播放。
- 展开为时值工作室后，左侧显示完整时值表和“间隔”列，右侧保留属性、节拍器和自动检测入口，底部增加可点击的 BPM 色带图。

### 13.2 判定线

**管理用 Inspector 展开态，当前线属性留在紧凑 Inspector。**

判定线需要树形层级、文件夹分组、拖拽排序、多选和批量操作，这些不适合塞进紧凑侧栏。因此拆成两个入口：

- **判定线管理**：展开态。
  - 左侧是判定线树和文件夹。
  - 右侧是选中线或批量选择的属性与操作。
  - 可以包含一个选中线的缩略预览区域。
  - 标题行右侧有返回按钮。

- **当前线属性**：紧凑 Inspector 页面。
  - 只显示当前活动线的常用属性。
  - 适合一边看时间轴一边微调。

这样，简单地改当前线属性不需要离开时间轴；需要整理线结构时才展开 Inspector。

### 13.3 素材

**整体使用 Inspector 展开态，成为素材工作室。**

素材需要文件夹树、网格、缩略图和大预览，是最不适合紧凑 Inspector 的一类内容。

素材工作室的布局：

- 左侧：文件夹树。
- 中部：素材网格。
- 右侧：选中素材的大预览、元数据和操作。
- 标题行右侧：返回按钮。
- 没有选中素材时，右侧详情不占位。

打开素材时 Inspector 覆盖 Workspace；收起后 Workspace 原样露出，播放头和判定线状态不变。

### 13.4 共同规则

- 三者的紧凑页默认不加宽 Inspector；需要更多内容时展开 Inspector 覆盖 Workspace。
- Inspector 不出现左右两列；需要更多内容时改为上下分层或分节。
- 放不进 Inspector 的内容，使用展开态，而不是把页面搬到 Workspace。
- 展开态必须有清晰的返回入口；返回按钮与展开按钮在同一标题行、同一槽位。
- 工作室展开 Inspector 覆盖 Workspace，不新增常驻面板，也不改变 Shell 的布局结构。

## 14. 动效与转场

展开不能让用户感觉“页面被换掉了”。它应该是 Inspector 本体向左长大，Workspace 留在原地被逐渐盖住；返回时 Inspector 收回。

### 14.1 原则

- **只有 Inspector 动。** Workspace 的尺寸、内容和播放状态都不变；时间轴不缩放、不换页、不重新布局。
- **展开就是变宽。** Inspector 的左边缘向左移动，直到覆盖 Workspace；不是把页面搬到另一个区域。
- **标题行连续。** 名称、帮助问号、展开/返回和关闭使用同一行、同一组槽位；返回按钮不跳到左侧。
- **方向清楚。** 展开向左长，返回向右收，使用同一套空间逻辑。
- **短。** 总时长控制在 180–240ms，避免用户等待动画。
- **可打断。** 转场期间接受 Esc；转场结束后焦点留在展开/返回按钮上。

### 14.2 推荐的转场

展开：

1. Inspector 宽度在 200–240ms 内从紧凑宽度增长到覆盖 Workspace 的宽度；Workspace 保持原尺寸。
2. Inspector 内容切换为宽布局：宽布局按最终宽度稳定铺在右侧，展开过程只揭开面板，不让内容随宽度重新排版；紧凑页在过渡和展开期间保持挂载但不可交互。
3. 标题行跟随 Inspector 左边缘移动；右侧动作组保持原位，焦点不跳。
4. 时间轴保持原位，被逐渐变宽的 Inspector 直接盖住；不淡出、不缩放、不换页。
5. 转场结束后，焦点仍在展开/返回按钮上。

返回：

- 使用同一段宽度动画反向播放；Inspector 收回进入前的宽度和页面。
- Workspace 原样露出，不播放横向滑入。
- 返回后恢复播放头、当前判定线和多线选择。
- 如果进入时暂停了播放，返回时恢复进入前的播放状态。

### 14.3 共享容器

展开不需要共享元素动画：Inspector 本身就是共享容器。标题行和按钮在展开前后保持同一位置，内容在同一面板内从紧凑布局切换为宽布局。

### 14.4 从侧边栏打开工作室

- 侧边栏项目保持选中状态。
- 先收起当前展开页，再打开目标 Inspector 页；Inspector 宽度回到紧凑范围。
- 不从侧边栏方向横向滑入；展开仍然只由 Inspector 宽度变化表达。

### 14.5 减少动态效果

- `prefers-reduced-motion` 下取消宽度过渡，直接切换展开态。
- 动画期间不阻塞 transport 和 Esc。
- 不使用整页路由转场或缩放整个应用窗口。

### 14.6 反模式

- 展开时 Inspector 向右收起或消失。
- 展开时 Workspace 缩小、换页或重新布局。
- 把工作室内容搬到 Workspace，再让 Inspector 收起。
- 返回按钮跑到标题行左侧。
- 转场超过 300ms，或需要等动画结束才能操作。
- 展开后没有任何返回入口。
- 转场后播放状态、播放头或当前判定线丢失。

### 14.7 待决策

- 展开时是否默认暂停播放？建议默认暂停并记住状态，返回时恢复。
- 窗口很窄时，展开态是否优先保证宽布局的最小宽度，还是允许内部横向滚动？

## 15. 三个 Inspector 页的落地形态

当前实现按“紧凑 Inspector + 展开态”落地。三个页面共用同一个规则：

- 侧边栏按钮打开紧凑 Inspector 页。
- 紧凑页把列表/树放在上方，把当前对象的属性放在下方；中间是可拖动的分栏缝，双击复位，方向键微调。
- 标题栏的“展开”把 Inspector 本体向左扩到覆盖 Workspace；页面内容留在 Inspector 内。
- 展开后标题行、帮助问号、返回和关闭按钮保持原来的槽位；返回按钮是展开按钮的同一位置和同一图形。
- 返回时 Inspector 收回展开前的宽度、页面和播放状态。
- 临时打开的展开态不写进会话恢复。
- 展开只改变 Inspector 宽度；Workspace 不换页、不缩放、不重新布局。
- 展开期间点击侧边栏任一页面，先收起当前展开页，再打开目标 Inspector 页。

### 15.1 时值

紧凑 Inspector：

- 上方是时间偏移、时值点列表和新增/删除。
- 下方是当前时值点的时间、BPM、节拍器，以及自动检测 BPM 与偏移值的入口。
- 选中列表行仍会移动播放头，便于一边听一边改。
- 没有时值点时，列表和新增占满页面，自动检测入口固定在底部，不显示空的属性分栏。

展开态：

- 左侧是完整时值表，增加“间隔”列，显示相邻时值点之间的拍数差。
- 右侧是当前时值点的属性、节拍器和自动检测入口。
- 底部新增时值图：每个时值点是一段可点击的 BPM 色带，点击后选中该点并移动播放头。
- 顶部汇总时值点数量、谱面偏移和最后一个时值点的位置。

### 15.2 判定线

紧凑 Inspector：

- 上方是判定线树和分组，底部固定新增判定线、新增分组和删除。
- 下方是当前线或多选线的属性，包括类型、绑定 UI、Z 顺序、遮罩、贴图、BPM 倍率和组合方式。
- 树的选择与属性表单共享同一份选择状态；不需要来回切换“列表/属性”视图。
- 没有判定线且没有选中文件夹时，树占满页面，不显示空的属性分栏。

展开态：

- 左侧是完整高度的判定线树，适合整理分组和在多选范围内批量修改。
- 右侧是属性表单，批量编辑和多选状态直接可见。
- 顶部汇总判定线数量、分组数量和当前选择数量。
- 属性表单下方是控制曲线编辑器，支持 X 位置、Y 位置、倾斜、大小和透明度五条轨道。
- 所有新增、删除、重命名、拖拽排序和批量操作仍在同一页面完成。

### 15.3 素材

紧凑 Inspector：

- 上方是文件夹树、导入素材、新建文件夹、删除分组。
- 下方是选中素材的预览、重命名和外部打开；图片、音频和 shader 使用各自的预览。
- 没有选中素材时，下方不显示详情区，文件夹树占满页面。

展开态：

- 左侧是素材树和导入/分组操作。
- 右侧是大预览、元数据和操作，图片按原始比例显示；没有选中素材时右侧不占位。
- 顶部汇总素材数量和文件夹数量。
- 导入、删除、重命名、文件夹整理和 shader 参数配置与紧凑页使用同一套行为。

### 15.4 判定线控制曲线

判定线的 X/Y 不是普通静态属性，而是 RPE 的 note control 曲线：横轴是音符下落距离，纵轴是该轨道在对应距离上的倍率或角度。

- X 位置使用 `posControl`，影响音符横向位置倍率。
- Y 位置使用 `yControl`，影响音符纵向位置倍率。
- 倾斜使用 `skewControl`，影响音符的横向剪切角。
- 大小和透明度分别使用 `sizeControl`、`alphaControl`。
- 曲线评估与运行时一致：控制点按距离排序，段内使用控制点自带的 `easing` 插值。
- 编辑方式：点击曲线区域添加点，拖动点改变距离或数值；选中点后可以在下方精确输入距离和数值。
- 手势期间只更新本地草稿，松开指针才提交一次，避免一次拖动产生几十条撤销记录。
- “重置曲线”删除该线的自定义轨道，回到中性默认；“删除点”删除当前选中的控制点。
- 紧凑 Inspector 显示同样的编辑器；展开态提供更高的曲线画布。

### 15.5 动效落地

- 展开时，Inspector 在 200–240ms 内从紧凑宽度向左生长到覆盖 Workspace 的宽度。
- Workspace 保持原尺寸；画布不淡出，被 Inspector 直接盖住。
- 展开面板复用当前封面图、模糊和亮度设置，再叠加与紧凑页相同的 50% 表面；背景图可见，但 Workspace 始终不会透出。
- 标题行跟随 Inspector 左边缘移动；问号、展开/返回和关闭保持原有槽位，返回按钮落在展开按钮的位置。
- 返回时 Inspector 收回原宽度，Workspace 原样露出，不额外淡出或淡入画布。
- 展开时暂停播放，并记录进入前的播放状态；返回时恢复。
- `prefers-reduced-motion` 下去掉宽度过渡，直接切换展开态。
- Escape 与“返回时间轴”走同一个退出动作；如果展开期间用户切换了 Inspector 页面，返回时不会强行覆盖当前页面。
